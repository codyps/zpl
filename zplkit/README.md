# zplkit (crates.io placeholder)

Version 0.0.0 is an empty placeholder for the ZPL toolkit from
[codyps/zpl](https://github.com/codyps/zpl). It exposes no Rust API.

For the implemented Rust parser and renderer, install the
[`zpl` crate](https://crates.io/crates/zpl). For Python, install
[`zplkit` from PyPI](https://pypi.org/project/zplkit/) with
`python -m pip install zplkit`; this crates.io package does not contain the
Python bindings.
