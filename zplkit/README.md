# zplkit

Version 0.0.0 is an empty placeholder for the ZPL toolkit from
[codyps/zpl](https://github.com/codyps/zpl). It exposes no API.

For the implemented Rust parser and renderer, use the
[`zpl` crate](https://crates.io/crates/zpl). Python bindings are developed in this
repository under the `zplkit` distribution and import name.
